# UPI Transaction Analysis Dashboard

An interactive Power BI dashboard that analyzes UPI transactions for the year 2024. It covers monthly transaction amounts, remaining balances, and a currency and city breakdown, with 10 slicers for filtering the data.

## Features

- Bookmark buttons to switch between 4 views (Line and Column charts for Amounts and Balance)
- 10 slicers: Bank Name Sent, Bank Name Received, Device Type, City, Gender, Age Group, Merchant Name, Payment Method, Purpose, Transaction Type
- Matrix with conditional formatting showing Amount and Remaining Balance by Currency, City and Month
- Data labels and clean formatting for easy reading

## Key Insights

- Transaction amount peaked in **May (1.707M)** and was lowest in **August (1.599M)**
- Remaining balance peaked in **June (8.54M)** and was lowest in **May (8.22M)**
- Monthly transaction amounts stay in a narrow range (about 1.6M to 1.7M), so activity is fairly stable through the year
- The matrix compares performance across EUR, GBP, INR and USD with Bangalore, Hyderabad, Mumbai and Delhi
